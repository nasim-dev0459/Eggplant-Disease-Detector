**Eggplant Shield** is a comprehensive end-to-end solution designed to identify and classify eggplant diseases using **Convolutional Neural Networks (CNN)**. This project bridges the gap between complex Deep Learning models and end-users through an intuitive **Flutter** mobile application.

## 📊 Dataset & Model Training
To ensure high accuracy, the model was trained on thousands of images focusing on common eggplant pathologies. Due to GitHub's file size limitations, the datasets are hosted on **Kaggle**.

### External Dataset Links:
*   🟢 **Healthy Leaves:** [Access on Kaggle](https://www.kaggle.com/datasets/mdnasimhawlader/healthy-datasheet)
*   🔴 **Cercospora Melongenae:** [Access on Kaggle](https://www.kaggle.com/datasets/mdnasimhawlader/cercospora-melongenae-disease-of-eggplant)

## 🛠️ Technical Stack
*   **Mobile Frontend:** Flutter & Dart (Cross-platform compatibility)
*   **Deep Learning:** Python, TensorFlow, Keras
*   **Image Processing:** Convolutional Neural Networks (CNN)
*   **Edge AI:** Model optimized via **TFLite** for real-time mobile inference

---

## 🚀 Key Features
*   **Real-time Diagnosis:** Get instant results using the phone's camera.
*   **Offline Functionality:** The model is deployed on-device, requiring no internet for core detection.
*   **High Accuracy:** Leverages advanced image augmentation techniques to handle various lighting and background conditions.
*   **Professional Documentation:** Includes full training notebooks for transparency and reproducibility.

## 📂 Project Roadmap
